# SmartKindergarten

SmartKindergarten is a university team project designed to simplify kindergarten management and communication between teachers, parents and administrative staff.

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- React
- JavaScript
- REST API
- JWT Authentication
- Git

## My contribution

I worked on the backend development of the following modules:

- **Attendance API** – child attendance management.
- **Daily Reports API** – creation and management of daily group reports.
- **Notifications API** – notification delivery and read status tracking.
- **Finance API** – payment management and financial status tracking.
- **System Settings API** – application configuration management.

My responsibilities included developing API endpoints, implementing business logic, creating DTO classes, database integration, input validation and role-based authorization.
